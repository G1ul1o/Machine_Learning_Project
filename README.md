# Machine_Learning_Project : Climate Change Trends Analysis
## Module : Machine Learning

During our semester we have to make a project in Machine Learning.
We have to choose some datasets that we will merged to examinate it.
We was free to choose any subject, we take climate changes because it's one of the main subject right now.

## Context
- Since 1880, annual global temperature has risen at an average rate of 0.08°C per decade.
- Rate of warming since 1982 is more than two times as fast: 0.20° C per decade.
- Global mean sea level has risen about 21–24 centimeters since 1880. 
- The rising water level is mostly due to a combination of melt water from glaciers and ice sheets and thermal expansion of seawater as it warms.

## Objectives
- Visualize the evolution of climate changes
- Predict the future of climate changes
- Realize the situation and raise awareness

## Datasets
- [Daily Temperature of Major Cities](https://www.kaggle.com/datasets/sudalairajkumar/daily-temperature-of-major-cities)\
- [Global Sea Level 1993 - 2021](https://www.kaggle.com/datasets/kkhandekar/global-sea-level-1993-2021)\
- [Daily atmosphere carbon dioxide concentration](https://www.kaggle.com/datasets/arunavsutar/daily-atmosphere-carbon-dioxide-concentration)\

Attention -> For the "Daily Temperature of Major Cities" dataset there is a problem with the API of Kaggle so we need to download it in the same folder of the file.
